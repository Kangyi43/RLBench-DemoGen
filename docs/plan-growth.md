# 增长计划：从数据生成工具到具身数据工厂

> 目标：扩大创新性与影响力，提升 GitHub 星标。策略 = **痛点工具 + 视觉冲击 + 生态寄生 + 内容分发**。
> 三个阶段按"先闭环、再深度、后声量"推进，每阶段独立可交付、可传播。

## 0. 北极星与判断标准

星标来自四件事，每个交付物至少命中一件：

| 杠杆 | 含义 | 本计划对应 |
|---|---|---|
| 痛点工具 | 大家都被折磨过的问题 | 格式导出（A1）、环境一键（已有） |
| 视觉冲击 | GIF/视频让人想转 | 训练回放 GIF（A3）、随机化预览（B2） |
| 生态寄生 | 依附高流量生态 | LeRobot/HuggingFace（A1、A4）、OpenVLA 教程 |
| 内容分发 | 双语教程/社区投放 | A4、C4 |

数据类型需求判断（调研结论）：**LeRobot 格式 > 训练预设 > 成功/失败配对 > 域随机化数据**。

## 1. 现状盘点

已有：Docker 一键环境、生成引擎（并行/续传/种子/16-bit 深度）、Web 可视化
（任务点选/真渲染预览/任务中断/数据浏览）、18 任务基准补全、法律合规结构。

已知缺陷（探索确认，纳入 A 阶段修复）：

1. `meta.json` 的 `camera_intrinsics/extrinsics` **全是 null** —— 读错了字段，
   真实值在 `obs.misc["<cam>_camera_intrinsics/extrinsics"]`（含 near/far）；
2. 每集种子用 `hash()` 派生，**跨进程不可复现**（Python 哈希加盐）；
3. 无动作字段（训练者都要自己推导）；
4. 输出只有原生格式，无 LeRobot/RLDS 等现代格式。

## 2. 阶段 A（P0）：格式出口与训练闭环（约 2 周）

**目标**：「一条命令：仿真 → LeRobot → 微调 ACT/DP → 回放 GIF」，这是星标基本盘。

| 编号 | 任务 | 内容 | 交付物 |
|---|---|---|---|
| A1 | LeRobot 导出器 | `scripts/convert_lerobot.py`：原生数据 → LeRobot v2.1 布局（每集 parquet + 每相机 mp4 + meta/*.json）。零 torch（pyarrow + av）；动作/状态预设：`eef-pose`/`eef-delta`/`joint`；相机/分辨率/语言标注可选；stats.json 统计 | 转换器 + 格式文档 |
| A2 | 数据质量修复 | 修内外参 bug（改读 `obs.misc`，含 near/far）、种子改稳定派生（hashlib）；导出选项并入 A1 CLI | 修复 + 校验 |
| A3 | 训练闭环教程 | `docs/train-act.md`：导出 → lerobot 训练 ACT/DP → 在本工具容器内回放评估 → GIF。torch 隔离在 `demogen-train` 附加服务（主镜像保持轻量） | 教程 + 回放脚本 + GIF |
| A4 | 发布物 | README 30s 演示视频；HuggingFace 数据集（18 任务 × 50 集 LeRobot 版）；中英双语；对比表（vs Isaac Lab/ManiSkill/robosuite）；发布投放清单（X/Reddit/HN/知乎） | 发布就绪包 |

验收：第三方按教程在 30 分钟内完成「生成 → 导出 → 训练 → 回放」，GIF 出片。

## 3. 阶段 B（P1）：可视化数据合成（约 3–4 周）

**目标**：把"可视化合成"做成护城河——全生态没人提供点击式域随机化。

| 编号 | 任务 | 内容 |
|---|---|---|
| B1 | 随机化引擎 | 每任务 YAML 随机化规格：干扰物（数量/位置/尺寸分布）、桌面材质、光照、相机抖动；围绕 `task.set_variation/reset` 钩子注入，种子可复现，参数写入 meta |
| B2 | Web 随机化面板 | 滑杆调参 + **9 宫格随机采样预览**（后端批量渲染 9 个随机实例）；与生成配置同 YAML 导出 |
| B3 | 自定义物体导入 | glTF/OBJ 拖入 → PyRep 网格导入 + 凸分解碰撞体；资产库面板（缩略图）。⚠️ 最高风险项，先 PoC 再铺 UI |
| B4 | 配对数据模式 | 成功示范 + 扰动失败回放成对产出（成败标签入 meta），为奖励模型/偏好训练供给（衔接 C1） |

验收：用户拖 3 个干扰物 + 设随机范围，9 实例无碰撞，生成数据过校验且 meta 记录随机化参数。

## 4. 阶段 C（P2）：创新声量（4 周+）

| 编号 | 任务 | 内容 |
|---|---|---|
| C1 | 配对数据集发布 | B4 数据打包为 HF 数据集（成功/失败对），标注用途（奖励模型/RLHF） |
| C2 | LLM 任务合成 | 自然语言 → 任务配置草稿 → 预览反馈闭环修正（GenSim 路线，复用 B 的成功条件/随机化原语） |
| C3 | 后端适配层 | 输出适配器抽象（LeRobot/RLDS/自定义）+ 仿真后端接口，路线图接 Isaac Lab/ManiSkill（绕开 RLBench 许可的商业限制） |
| C4 | 传播资产 | 落地页（GitHub Pages）、演示视频集、社区分发与迭代 |

## 5. 工程约束（延续既有规范）

- 代码零注释（含 docstring）；README 精简、特点/适用场景置顶；
- 法律零再分发：不嵌入 RLBench/PyRep/CoppeliaSim 源码，安装包与 tasks_extra 不入 git；
- 主镜像不装 torch（训练用独立 `demogen-train` 服务）；x86_64 + Docker 化交付；
- 新增字段保持 `data-format.md` 自描述同步；校验器（verify.py）同步覆盖新产物。

## 6. 里程碑

1. **M1（A1+A2 完成）**：LeRobot 导出可用，数据缺陷修复 —— 本次实施；
2. **M2（A3+A4 完成）**：训练 GIF 出片、发布包就绪 —— 首个传播节点；
3. **M3（B 完成）**：可视化合成能力上线 —— 差异化护城河；
4. **M4（C 完成）**：数据集 + LLM 合成 + 多后端 —— 声量高峰。
