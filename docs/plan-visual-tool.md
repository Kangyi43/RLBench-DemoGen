# 可视化数据生成工具 · 路线图

> 当前版本已实现「可视化配置器」（点选任务/参数 + 真渲染预览 + 一键生成 + 数据浏览）。
> 以下为后续两阶段规划，难度递增。竞品调研见 [survey-visual-tools.md](survey-visual-tools.md)。

## 现状与共用架构

```
浏览器前端（配置面板 / 预览 / 控制台 / 数据浏览）
        │  HTTP
        ▼
FastAPI 后端 ── ① 读任务清单  ② 预览渲染  ③ 下发/中断生成任务
        ▼
生成引擎 scripts/generate.py（并行/续传/种子/校验）
        + 常驻仿真器（预览 = 真渲染，非假图）
        ▼
Docker 环境（一键构建，已固化全部安装坑）
```

关键设计：预览用 headless 仿真器真渲染（所见即所得）；所有交互落成单一
YAML 配置，界面与命令行等价；CoppeliaSim 实例池常驻，避免点击冷启动。

## 阶段一 · 交互式场景编辑器（⭐⭐⭐，2–4 周）

**目标**：开放"场景内容"——3D 拖拽摆放物品、添加干扰物、调随机化范围。

- Three.js 场景视图：点选物体、拖拽位姿；资产面板拖入干扰物；
- 随机化面板：位置/朝向/尺寸抖动范围滑杆 + 一次看 9 个随机实例拼图；
- 冲突检测：摆放后实时碰撞/可达性检查（PyRep 运动学求解）；
- 场景配置 YAML 版本化（git 式 diff，可分享）。

技术要点：前端场景树 ↔ 后端 PyRep 程序化场景双向同步；.ttt → glTF 资产管线
（先支持程序化几何体 + 常用资产包）。验收：拖入 3 个干扰物 + 随机范围 →
9 实例无碰撞 → 生成数据 100% 通过校验。

## 阶段二 · 新任务脚手架（⭐⭐⭐⭐，4–8 周）

**目标**：不写代码，配置 + 示例教出一个全新任务并生成其演示数据。

- 成功条件模板库（DetectedCondition / ProximitySensor / GraspedCondition 拖拽组合）；
- 航点示教面板（拖虚拟夹爪记录位姿 / 轨迹微调回放）→ 生成任务 .py；
- 自动验证环：脚本专家试跑 + 成功率报表 + 失败航点高亮；
- 任务包导出（.ttt + .py + 配置 + 文档），可直接被本工具收录批量生成。

验收：30 分钟造出"把方块放进碗"任务，专家成功率 ≥ 80%，数据通过校验。
风险：任务模板表达力（模板外任务仍需写代码，界面将提供"高级模式落码"双轨）。

## 远期扩展（列出但不做承诺）

- LLM 辅助造任务（GenSim 路线）：自然语言 → 任务配置草稿 → 界面微调；
- 场景增广（MimicGen 路线）：从已有 demo 泛化新场景布局；
- LeRobot / RLDS 格式导出器；
- 遥操作录制（键盘/手柄）产出人类演示，与脚本专家数据混合。

## 风险与依赖

| 风险 | 影响 | 缓解 |
|---|---|---|
| .ttt → glTF 资产管线工作量 | 阶段一延期 | 先程序化几何体，逐步扩充 |
| 预览渲染延迟（软件渲染秒级） | 体验 | 实例池常驻 + 低分辨率预览 + 异步队列 |
| 任务模板表达力不足 | 阶段二覆盖率 | 模板 + 落码双轨 |
| RLBench 许可约束 | 分发 | 继续零再分发（见 [legal-compliance.md](legal-compliance.md)） |
